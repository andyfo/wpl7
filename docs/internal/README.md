# Internal

Maintainer runbooks. Not part of the documentation an operator needs, and not promises about
anything — they are checklists for one-time procedures and for what has to be checked again,
written down so they are not reconstructed from memory at the moment they matter.

| | |
|---|---|
| [watchlist.md](watchlist.md) | Upstream bugs we work around, versions we pin, services we call: each with a priority, when it was last checked, and what to do when it changes |
| [import-protocol.md](import-protocol.md) | How the panel copies a site through the WPL7 Migrate plugin: transports, signing, every action and the SQL it writes. Normative, and changed together with the plugin |
| [docs-site-plan.md](docs-site-plan.md) | The public documentation site (wpl7.com/docs): structure, style, tooling, screenshots, the checks that keep it in step with the code, and the work packages to build it |
