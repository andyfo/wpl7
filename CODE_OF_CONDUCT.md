# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

The short version: be decent. Assume the person you are replying to is competent and acting
in good faith. Criticise code and arguments, never people. English is not everyone's first
language, and a terse comment is usually terseness rather than rudeness.

Unacceptable behaviour includes harassment, personal attacks, discriminatory language, and
publishing anyone's private information.

Report a problem privately to the repository owner, through the email address in their GitHub
profile. Reports are handled confidentially. The maintainer may remove comments, close
issues, or block accounts, and will say why.

The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
